## Why

Адмін-панель Smarket наразі підтримує лише світлу тему, що може бути незручним для адміністраторів під час тривалої роботи. Оскільки макети темної теми будуть надані згодом, зараз необхідно виконати базову підготовку інфраструктури фронтенду: налаштувати змінні кольорів, адаптувати Tailwind-конфігурацію для підтримки dark mode та додати перемикач теми. Це дозволить швидко і безболісно натягнути нові макети, коли вони будуть готові.

## What Changes

- Додавання глобального стану у Zustand (`useThemeStore`) для зберігання обраної теми (світла/темна/системна) з персистенцією у `localStorage`.
- Налаштування Tailwind CSS для підтримки класу `dark` (`darkMode: 'class'`).
- Підготовка глобального CSS (`index.css`) та введення базових CSS-змінних (design tokens) для підтримки темної теми.
- Впровадження логіки (наприклад, `useEffect` хук) для автоматичного застосування класу `dark` до тегу `<html>` або кореневого контейнера залежно від обраної теми.

## Capabilities

### New Capabilities
- `admin-theme-management`: Керування станом теми користувача в адмін-панелі (світла/темна/системна), збереження налаштувань.

### Modified Capabilities
- `admin-panel-styling`: Підготовка структури стилів для dark mode, перехід на використання гнучких змінних кольору замість хардкоду.

## Impact

- `apps/react/tailwind.config.js` та `apps/react/src/index.css`: Налаштування dark mode та CSS-змінних.
- `apps/react/src/store/`: Новий стор для керування темою.
- `apps/react/src/App.tsx` (або кореневий layout адмін-панелі): Логіка застосування CSS-класу `dark`.
