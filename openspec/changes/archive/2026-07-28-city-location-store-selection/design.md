## Context

Магазини в системі Smarket містять дані про місто (`city`), адресу (`address`), широту/довготу (`lat`, `lng`) у PostgreSQL таблиці `stores`.
Однак на фронтенді додаток завантажував представників мереж без фільтрації за населеним пунктом клієнта.
Для надання персоналізованого сервісу агрегації цін потрібно додати підсистему вибору міста клієнта та наскрізне фільтрування.

## Goals / Non-Goals

**Goals:**
- Забезпечити збереження міста клієнта у Zustand store (`locationStore`) та `localStorage` / `user.settings`.
- Створити бекенд API `GET /api/v1/stores/cities` для отримання списку доступних міст та кількості магазинів.
- Додати компонент вибору міста у Header з автовизначенням геолокації клієнта.
- Здійснювати фільтрацію супермаркетів на сторінці `/shops` та товарів у каталозі / пошуці за обраним містом.

**Non-Goals:**
- Точний розрахунок відстані до конкретного будинку клієнта (на даному етапі фільтрація здійснюється за містом).
- Зміна механізму парсингу Zakaz API ETL-воркером.

## Decisions

### 1. Zustand Store для клієнтської локації
- **Рішення**: Створення `locationStore` із викликом `fetchCities()` та вибором міста за замовчуванням ("Київ").
- **Альтернативи**: React Context / useState. Вибрано Zustand задля високої продуктивності, персистенції `localStorage` та відсутності зайвих ререндерів у всьому додатку.

### 2. Ендпоінт міст у `product_service`
- **Рішення**: Додати SQL-запит `SELECT city, COUNT(*) FROM stores WHERE is_active = true GROUP BY city ORDER BY count DESC`.
- **Обґрунтування**: Оптимальний запит у PostgreSQL згрупований за містом.

### 3. Фільтрація в Meilisearch
- **Рішення**: У `search_service` перед формуванням результатів пошуку фільтрувати товари за `store_id` або мережею відповідно до обраного міста.

## Risks / Trade-offs

- **[Risk]** Невідома геолокація користувача або заборона доступу до гео-покупок в браузері.
  - *Mitigation*: Фолбек на замовчуванням місто ("Київ") з можливістю швидкої зміни вручну.
- **[Risk]** Відсутність товарів у певному малому місті.
  - *Mitigation*: Відображення плашки з пропозицією змінити місто або переглянути найближчі супермаркети.
