# 🌟 Promin AI Agent

**Promin** (Промінь / Ray) — это интеллектуальный микросервис-ассистент для поиска товаров, сравнения цен и управления корзиной на базе фреймворка **Pydantic AI** и модели **Google Gemini 2.0 Flash**.

Сервис работает как независимый компонент в составе агрегатора цен **Smarket**, помогая пользователям находить наиболее выгодные предложения в супермаркетах в режиме реального времени.

---

## 🏗️ Архитектура и взаимодействие

Promin спроектирован как изолированный микросервис, общающийся с остальной частью системы исключительно по HTTP API:

```
[ Frontend React ]
        │
        ▼ (JWT Auth)
[ API Gateway :8080 ]
        │
        ▼ (X-User-Id)
[ promin_agent :8005 ] <───> [ Google Gemini API ]
        │
        ├─► [ search_service :8083 ] ──► (Поиск товаров в Meilisearch)
        ├─► [ product_service :8000 ] ──► (Сравнение цен в сетях)
        └─► [ cart_service :8002 ] ────► (Добавление и просмотр корзины)
```

---

## 🛠️ Инструменты агента (Tools)

Агент Promin управляет выполнением следующих встроенных Python-функций:

1.  **Поиск в каталоге (`search_catalog`)**:
    *   *Назначение*: Ищет продукты по названию во всех супермаркетах.
    *   *Источник*: Запросы к `search_service` (Meilisearch).
2.  **Сравнение цен (`compare_product_offers`)**:
    *   *Назначение*: Сравнивает стоимость конкретного продукта во всех сетях (Ашан, Novus, Metro).
    *   *Источник*: Запросы к `product_service` (PostgreSQL).
3.  **Просмотр корзины (`get_user_cart`)**:
    *   *Назначение*: Выводит список продуктов и общую стоимость текущей корзины пользователя.
    *   *Источник*: Запросы к `cart_service`.
4.  **Добавление в корзину (`add_product_to_cart`)**:
    *   *Назначение*: Позволяет ИИ добавлять найденные продукты в корзину пользователя.
    *   *Источник*: Запросы к `cart_service`.

## 🚀 Настройка и запуск

Для запуска сервиса необходимы следующие переменные окружения:

| Переменная | Описание |
| :--- | :--- |
| `GEMINI_API_KEY` | Валидный API-ключ для доступа к моделям Google Gemini |
| `SEARCH_SERVICE_URL` | Внутренний URL сервиса поиска (`http://search_service:8888/api/v1`) |
| `PRODUCT_SERVICE_URL` | Внутренний URL каталога товаров (`http://product_service:8000/api/v1`) |
| `CART_SERVICE_URL` | Внутренний URL корзины (`http://cart_service:8002/cart`) |
